# HEDAMO Track A – Product & Communication Assignment

## Project Overview

This submission presents a product design proposal for **Track A – Product & Communication** of the AFAP Assessment.

The objective was not to redesign HEDAMO as a new product, but to improve the first-time user experience while preserving its philosophy, research-oriented identity, and purpose.

The solution focuses on improving homepage clarity, producer application transparency, and prioritising future product improvements using evidence-based product thinking.

---

# Problem Statement

During the Common HEDAMO Diagnostic, I observed that first-time visitors may require significant scrolling before clearly understanding:

- What HEDAMO is
- Who it serves
- Why it exists
- What action they should take

The homepage communicates the philosophy effectively, but the product value proposition becomes clear only after exploring multiple sections.

The redesign focuses on reducing this "time-to-understanding" while maintaining HEDAMO's editorial design language and research-oriented positioning.

---

# Primary User

### Producer

A producer visiting HEDAMO wants to quickly understand:

- What HEDAMO does
- Whether it is relevant to their products
- How to begin a product declaration

### Secondary User

Reviewer

A reviewer needs a transparent workflow showing application progress and current review status.

---

# Scope

This prototype includes:

- Homepage first-screen redesign
- Improved information hierarchy
- Clearer value proposition
- Updated call-to-actions
- Producer Application Status Flow
- Prioritised Product Backlog
- Responsive frontend prototype

This submission is intended as a UX and product-thinking prototype.

It is **not** intended to be a production-ready implementation.

---

# Solution Overview

The redesign introduces several focused improvements:

- Simplified homepage messaging
- Faster first-time comprehension
- Better CTA hierarchy
- Trust indicators
- Improved producer application workflow
- Transparent application status timeline
- Product backlog prioritised using Impact vs. Effort

The objective was to improve usability without changing HEDAMO's mission or visual identity.
