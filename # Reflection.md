# Reflection

## Project Summary

This project was completed as part of the AFAP Track A assessment for HEDAMO. The objective was to improve the first-screen homepage experience, design a transparent producer application status flow, and create a prioritised product backlog while preserving HEDAMO's philosophy and research-oriented identity.

# What Challenged Me

The biggest challenge was understanding HEDAMO's purpose without treating it like a traditional SaaS product.

Initially, I focused on visual improvements, but after studying the platform more carefully, I realised the real opportunity was improving first-time comprehension while preserving the existing philosophy and editorial identity.

Balancing clarity with HEDAMO's research-oriented communication style required several design iterations.

---

# What Failed

Some early homepage concepts introduced modern SaaS design patterns that did not align with HEDAMO's visual language.

The hero section also became text-heavy during early iterations, making it difficult for users to quickly understand the product.

These approaches were discarded in favour of a simpler information hierarchy with clearer messaging and better visual balance.

---

# AI Usage

Artificial Intelligence significantly accelerated ideation, UI generation, and documentation.

However, AI-generated layouts and content were not accepted directly.

Each suggestion was manually reviewed, refined, and compared against the original HEDAMO website to ensure consistency with the platform's philosophy and assignment objectives.

---

# What I Would Automate Next

Given additional time, I would automate:

- Producer onboarding workflow
- Product declaration forms
- Application status notifications
- Reviewer workflow
- Product profile generation
- Analytics for user engagement
- Usability testing metrics collection

---

# What I Would Improve With One Additional Day

If I had one more day, I would focus on improving the quality rather than adding new features.

Planned improvements would include:

- Conduct usability testing with first-time users.
- Refine typography and spacing based on feedback.
- Improve accessibility and keyboard navigation.
- Optimise animations and performance.
- Add richer interaction states and empty states.
- Expand the prototype with realistic application data.

---

# Key Learning

This assignment reinforced that effective product design is not about creating a completely new interface. It is about understanding user problems, making evidence-based decisions, and improving the experience while respecting the product's existing purpose and identity.

The process also highlighted the importance of combining AI-assisted development with human judgement, validation, and iterative refinement.
