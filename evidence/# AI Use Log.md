# AI Use Log

## Overview

Artificial Intelligence was used as a productivity and ideation tool throughout this assignment. AI assisted with brainstorming, content refinement, UI generation, and rapid prototyping. All final product decisions, prioritisation, validation, and documentation were manually reviewed and refined before inclusion in the submission.

---

# AI Tools Used

| Tool | Purpose |
|------|---------|
| ChatGPT (GPT-5.5) | UX research support, product thinking, content refinement, documentation, decision review |
| Lovable | Frontend UI generation, React component generation, rapid prototyping |
| GitHub Copilot | Minor code completion and refactoring |

---

# Representative Prompt 1

## Objective

Redesign the HEDAMO homepage while preserving its philosophy and improving first-time user comprehension.

### Prompt Summary

"Analyse the current HEDAMO homepage, preserve its editorial design language, and redesign only the first-screen experience to help producers understand the platform more quickly without changing its research-oriented identity."

### AI Output

Generated an improved homepage layout including:

- Improved information hierarchy
- Clearer value proposition
- Better CTA placement
- Simplified hero section
- Responsive component structure

### Manual Changes

The generated layout contained excessive text and several generic SaaS design patterns.

I manually:

- Simplified the hero content
- Improved spacing
- Reduced cognitive load
- Replaced generic copy with product-specific messaging
- Adjusted component hierarchy to better match HEDAMO's identity

# Representative Prompt 2

## Objective

Generate a producer application workflow.

### Prompt Summary

"Design a producer application status flow with transparent progress states."

### AI Output

Generated a workflow containing:

- Submitted
- Needs Information
- Under Review
- Approved
- Not Proceeding

### Manual Changes

I reorganised the workflow into a clearer timeline, improved the visual hierarchy, and refined labels and interactions to better communicate application progress.

---

# What AI Got Wrong

AI occasionally:

- Generated generic SaaS UI patterns that did not match HEDAMO's editorial style.
- Added unnecessary marketing language.
- Produced overly verbose content.
- Suggested features outside the assignment scope.
- Prioritised aesthetics over product communication.

These outputs were not used directly.

---

# Verification Process

Every AI-generated suggestion was manually reviewed.

Verification included:

- Comparing the redesign against the original HEDAMO website.
- Checking that the redesign preserved the company's philosophy and visual identity.
- Ensuring every change addressed an observed usability issue.
- Reviewing responsiveness across different screen sizes.
- Testing navigation, interactions, and user flow.

No AI-generated content was accepted without manual review and refinement.

---

# Human Decisions

The following decisions were made manually rather than by AI:

- UX problem identification
- Product prioritisation
- Homepage information hierarchy
- Application workflow structure
- Product backlog prioritisation
- Final copy refinement
- Overall design direction
- Submission documentation

---

# Summary

AI accelerated ideation, prototyping, and content generation, but final product decisions, validation, prioritisation, and quality assurance were performed manually. The final submission reflects a combination of AI-assisted implementation and independent product thinking.
